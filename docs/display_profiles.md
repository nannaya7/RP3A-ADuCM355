# 화면 프로파일: 가로(1280x800) / 세로(480x800) 자동 선택

> 구현 현황. 검증: PC(Python 3.11.6)에서 오프스크린 렌더링과 자동 테스트(전체 129개 통과). **Pi의 세로 DSI 패널 실기 확인은 아직 하지 않았다.**

## 1. 선택 규칙 (시작할 때 한 번)

```
화면 고르기  : config [display] screen 이름 → 없으면 주 화면 (화면이 2개 이상이면 경고)
프로파일     : config [display] profile = auto | landscape | portrait
  auto       : 선택한 화면의 크기에서 가로 ≥ 세로 이면 landscape(1280x800), 아니면 portrait(480x800)
```
- 실행 중 화면 방향 전환은 없다 (확정). 시작할 때 감지한 값으로 끝까지 간다.
- **회전은 OS가 한다.** DSI 패널을 OS 설정(Screen Configuration, `wlr-randr`)에서 돌려 두면 Qt가 회전된 크기를 보고하고, 앱은 그 결과만 본다. 앱 안에서 따로 회전하지 않는다.
- 표준(1280x800 / 480x800)이 아닌 해상도는 방향만 보고 고르며 `표준과 다릅니다` 경고를 남긴다 (레이아웃이 어긋날 수 있음).
- `profile`을 `landscape`/`portrait`로 고정했는데 화면 방향과 다르면 설정을 따르되 경고를 남긴다.
- 명령줄 우선: `python main.py --profile portrait --screen DSI-1` (설정 파일보다 우선).

## 2. 화면이 여러 개일 때 (예: DSI + HDMI)
- 두 화면이 연결되어 있으면 작업표시줄이 HDMI에만 보이거나, 주 화면이 HDMI로 잡혀 해상도 감지가 엉뚱한 화면을 볼 수 있다.
- `config.ini`의 `[display] screen = DSI-1`로 사용할 화면을 이름으로 지정한다. 이름은 `wlr-randr`에 나오는 출력 이름(또는 Qt의 `screen.name()`)이다.
- 지정하지 않고 화면이 2개 이상이면 주 화면을 쓰고 경고 로그를 남긴다.
- 지정한 화면으로 창을 옮기고(`move`), Wayland에서는 `windowHandle().setScreen()`도 시도한다. **이 동작은 PC에서 확인하지 못했다(화면이 1개).** Pi에서 확인이 필요하다.

## 3. 설정 변경 (Pi의 `config.ini`)
기존 Pi의 `config.ini`는 `profile = landscape`로 고정되어 있을 수 있다. 자동 선택을 쓰려면 직접 바꾼다.
```ini
[display]
profile = auto
; 화면이 여러 개이면 이름 지정 (예: DSI-1). 비우면 주 화면
screen =
fullscreen = true
```

## 4. 세로(480x800) 로그인 — 시안 기준
위에서 아래로: **사진(좌측 상단에 로고) → 헤드라인 → 역할 탭 → ID → PW → 로그인 유지/비밀번호 찾기 → [로그인 | 건너뛰기] (한 줄, 3 : 2)**

| 요소 | 내용 |
|---|---|
| 위쪽 사진 | `assets/login-hero-photo.png`(가로 사진을 크롭·페이드). 폭에 맞춰 축소하고 남는 높이에 맞춰 아래를 잘라 배경색으로 녹인다 |
| 로고 | **사진의 좌측 상단**(여백 20, 18)에 얹는다. 레이아웃에 들어가지 않아 다른 요소의 위치는 그대로이고, 하단 로고가 빠진 만큼 사진이 조금 커진다. 키보드가 열려 사진이 접히면 로고도 함께 숨는다 |
| 헤드라인 | "보다 나은 삶,"(진한 회색) / "진단에서 시작합니다."(녹색). **사진 아래쪽 흐려지는 부분(세로 중심 y=380)에 얹는다** (`HEADLINE_CENTER_Y`). 사진의 자식이라 키보드가 열려 사진이 접히면 함께 숨는다 |
| 입력 영역 위치 | 역할 탭~회원가입 안내를 시안 선까지 **51px 올렸다** (`BODY_LIFT`, 아래 여백으로 구현). 역할 탭 y=463, 로그인 버튼 y=683. 키보드가 열리면 이 여백은 없앤다 |
| 역할 탭 | 일반 회원 / 의료진 / 의료기관 (가로는 일반/의료진/기관) |
| 입력란 | 높이 52, 흰 배경, 글자 16px (터치용) |
| 로그인 유지 | 체크박스 24px. **기본 해제** (시안 이미지에는 체크되어 있었으나 기본값은 가로와 같이 해제로 둠) |
| 로그인 / 건너뛰기 | **한 줄에 나란히, 폭 3 : 2**, 높이 52. 건너뛰기 글씨는 "건너뛰기"(개발용 표기 없음). `skip_login = false`이면 건너뛰기를 만들지 않고 로그인 버튼이 전폭이 된다. 가로 화면도 같은 방식(높이 44, 3 : 2, 로그인 버튼 바로 옆). |
| 회원가입 안내 | 버튼 아래에 가로와 같은 문구 "아직 엔포마레 회원이 아니신가요? 회원가입"(높이 24, 간격 8). 이 줄만큼 아래 여백을 줄여 위쪽 위치는 그대로. 키보드가 열리면 숨김. 링크는 아직 동작 없음 |

### 터치 키보드와 화면 가림
- 키보드(높이 약 335px)가 열리면 **위쪽 사진(과 그 위의 로고)을 접어서** 헤드라인부터 건너뛰기 버튼까지 키보드 위에 모두 보이게 한다. 닫으면 사진이 돌아온다.
- 세로에서는 키보드가 compact 모드: 키 간격 5px, 좌우 여백 8px, 글자 18px. 숫자 줄 키 폭은 약 36px, 글자 줄은 약 41px, 높이 56px. **실제 패널에서 손가락 크기에 맞는지 확인이 필요하다.**
- 한/영, 기호, 완료 키는 세로에서도 같은 위치에 있다.

### 가로 로그인 변경 (2026-10-24)
| 요소 | 내용 |
|---|---|
| 좌측 상단 문구 | 세로와 같은 헤드라인을 (42, 40)에 왼쪽 정렬로 얹는다. 글꼴 31px(세로 24px의 +30%), `#landscapeHeadline` |
| 로그인 카드 위치 | 가운데에서 **아래로 110px** (`CARD_DROP`; 70→140으로 내렸다가 30px 올림). 카드 아래 끝 y≈740 |
| 키보드가 열리면 | 카드를 가운데로 되돌리고 문구는 숨긴다 (실기 확인 필요) |

## 5. 세로 측정 화면 — 임시 배치 (시안 전)
세로 시안이 없어서 **로직은 그대로 두고 배치만 임시로 바꿨다.** → **2026-10-25 시안 반영 완료**: 세로 측정 화면은 `ui/dashboard_portrait.py` (`docs/measure_dashboard.md` §6). 아래 임시 배치 설명은 이전 기록이다.
- 카드를 세로로 쌓음(안내/타이머/진행 → 센서), 단계 칩은 `T0 T1 T2`만 표시
- 센서 행은 점 수 대신 진행 막대와 상태만 표시 (점 수는 위 진행 문구에 `n / 303 점`)
- 버튼: `처음부터`, `중지`를 한 줄에 반씩, `T0 시작` 같은 주 버튼은 전폭
- 완료 시 결과 카드가 큰 카드 안에 나타나고 안내/타이머/진행 막대는 접힌다
- `"← 로그인으로"` 버튼은 세로에서 `"← 뒤로"`로 줄였다

## 6. 코드 위치
| 항목 | 위치 |
|---|---|
| 프로파일, 선택 규칙, 화면 고르기 | `app/display.py` (`select_profile`, `pick_screen`) |
| 화면 선택과 창 배치 | `main.py` |
| 세로 로그인 | `ui/login_page.py` (`_build_portrait`, `HeroImage`, `on_keyboard`, 로고 위치 `LOGO_MARGIN_X/Y`) |
| 입력란/탭 크기 옵션 | `ui/widgets.py` (`Field(height, large)`, `RoleTabs(height, font_px, track)`) |
| 키보드 compact, 표시 신호 | `ui/virtual_keyboard.py` (`compact`, `visibilityChanged`) |
| 스타일 | `ui/theme.qss` (`[touch="true"]`, `#vkb[compact="true"]`, `#measurePage[compact="true"]`) |
| 테스트 | `tests/test_display.py`, `tests/test_portrait_ui.py` |

> 스타일 속성 이름에 **`size`를 쓰면 안 된다.** QWidget의 기본 속성(`size`)과 충돌해 값이 적용되지 않는다. 그래서 `touch`, `compact`를 쓴다.

## 7. Pi에서 실행하는 방법 (둘 다 사용자 확인 완료, 2026-10-24)
| 방법 | 명령 |
|---|---|
| **VNC 안의 터미널 / Pi 화면의 터미널** | `python3 main.py` (화면 연결 정보가 이미 있음) |
| **SSH** (화면은 Pi 패널에 뜸) | `export XDG_RUNTIME_DIR=/run/user/$(id -u)` → `export WAYLAND_DISPLAY=wayland-0` → `QT_QPA_PLATFORM=wayland python3 main.py` |
- SSH에서 환경 변수 없이 실행하면 `qt.qpa.xcb: could not connect to display`가 난다 (SSH 터미널에는 화면 정보가 없기 때문). 앱 문제가 아니다.
- `WAYLAND_DISPLAY` 이름은 `ls /run/user/$(id -u) | grep wayland`로 확인한다 (`wayland-0` 또는 `wayland-1`).
