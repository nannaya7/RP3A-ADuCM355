# 작업 기록 — 2026-10-24

## 1. 오늘 한 일 (로그인 화면 마무리)

### 세로 (480x800)
1. 하단 로고를 **사진 좌측 상단**으로 이동 (여백 20, 18). 레이아웃 밖이라 다른 요소 위치는 그대로.
2. 로그인 버튼을 폭 **3 : 2**로 줄이고 옆에 **건너뛰기** 버튼. "(개발용)" 글씨 삭제. `skip_login=false`이면 로그인 버튼 전폭.
3. 헤드라인 "보다 나은 삶, 진단에서 시작합니다."를 사진 아래쪽(중심 y=380)으로 이동. 사진의 자식으로 얹음.
4. 입력 영역(역할 탭~버튼)을 시안 선까지 **51px 위로** (`BODY_LIFT`).
5. 헤드라인 아래쪽이 잘리던 문제 수정: 사진 영역이 글씨 끝(y=409)보다 짧아서였다. 빈 칸을 줄여 사진 영역을 449px로.
6. 버튼 아래에 **회원가입 안내** 추가 (가로와 같은 문구). 키보드가 열리면 숨김.

### 가로 (1280x800)
1. 로그인/건너뛰기를 세로처럼 **한 줄 3 : 2** (높이 44), 글씨 "건너뛰기". 회원가입 안내는 그 아래에 그대로.
2. 좌측 상단에 헤드라인 추가 (세로와 같은 글꼴·색, 31px = 세로의 +30%).
3. 로그인 카드를 가운데에서 아래로 **110px** (`CARD_DROP`).
4. 키보드가 열리면 카드를 가운데로 되돌리고 문구 숨김.
