# 가로 측정 화면 (대시보드) — 2026-10-25

시안(환자 프로필 / 검사 결과 / 검사 진행 / 장비 상태 / 검사 이력)대로 만든 **가로(1280x800) 측정 화면**이다.
세로(480x800) 화면은 §6. 두 화면은 같은 컨트롤러와 표시 로직(`ui/dashboard_logic.py`)을 쓰고 배치만 다르다.
코드: `ui/dashboard_page.py`(가로), `ui/dashboard_portrait.py`(세로), `ui/dashboard_logic.py`(공통), `ui/dashboard_widgets.py`, `measure/patient.py`, `measure/history.py`, 스타일은 `ui/theme.qss` 맨 아래.

## 1. 구성
| 영역 | 내용 |
|---|---|
| 상단 | `←`(로그인 화면으로), 모델 탭 `Troponin` / `NT-ProBNP`, 날짜·시간, 우측 끝은 설정 버튼 |
| 환자 프로필 | **필수** 성명, 성별, 나이, 몸무게 / **옵션** 혈압(수축/이완), 혈당, 만성질환(다중 선택 칩) |
| 검사 결과 | 값(큰 글씨), 단위, 정상/주의 표시, 참고 범위, 측정 시간 / 검증 완료 시간 / 검사 방법, 헤더의 `검증 완료` 배지 |
| 검사 진행 | 1단계 시료준비 → 2단계 혈액투입 → 3단계 세척후 검증 카드. 오른쪽 위에 `처음부터` `중지` `모니터링` `측정 시작` |
| 장비 상태 | **아이콘 3개**(세로 화면과 같음, `DeviceStatusPanel`): 장비(모듈 응답) / 키트(센서·신호 포화) / 연결(UART 포트). 정상은 초록, 주의(신호 포화)는 주황, 문제는 빨강. 모듈 정보(FW·보정·보드)는 아이콘의 툴팁. 이전의 "진행 상태 n / 3 단계", "센서 n / 3" 진행 막대는 없앴다 (진행은 검사 진행 카드에 이미 보인다) |
| 검사 이력 | 지난 검사(날짜/시간, 항목, 결과, 상태). 손가락으로 밀어서 최근 20건까지 |

단계 카드의 상태 글씨: `대기` / `시작 대기` / `반응 중`(혈액투입 타이머) / `측정 중` / `계산 중` / `완료` / `검증 완료`(3단계) / `오류` / `모듈 없음`.
활성 카드는 파란 테두리, 혈액투입 대기 중에는 `12:34 / 15:00` 과 진행률(%), 측정 중에는 `n / 303 점` 과 진행률을 보인다.

## 2. 동작
- **환자 필수 정보**: 성명·성별·나이·몸무게를 채워야 **1단계 `측정 시작`** 이 동작한다. 비어 있으면 시작하지 않고 빈 칸을 빨간 테두리로 표시하며 위쪽에 안내가 뜬다. 끄려면 `config.ini [measure] require_patient = false`.
- 입력값은 `result.json`(`patient`)과 `summary.json` 에 함께 저장된다. **이름 등 개인정보가 들어가므로** `results/` 를 밖으로 내보낼 때 주의한다.
- **새 측정**(결과 화면에서 주 버튼)을 누르면 이전 환자 정보를 **지운다** (다음 환자에게 남지 않게). `처음부터`는 정보를 남긴다.
- `NT-ProBNP` 탭: 아직 모델이 없어 누르면 "준비 중" 안내만 뜬다.
- 키보드: 입력란이 모두 화면 위쪽에 있어 터치 키보드가 열려도 가려지지 않는다. 만성질환은 칸을 누르면 목록(체크)이 열린다.
- 이력: 검사가 끝나면 `summary.json` 이 저장되고 목록이 갱신된다. 이력이 안 보이면 `results/` 안에 `summary.json` 이 있는지 확인.

## 3. 단위 / 참고 범위 (**확정 전까지 비워 둠**)
시안에는 `ng/mL`, 참고 범위 `0.000 – 0.040`, 정상/주의 표시가 있지만, **모델의 농도 단위가 아직 확정되지 않았다** (`docs/model_troponin_eis.md` §10). 모델 값은 지금 `29.7` 같은 큰 숫자라, 시안의 값을 그대로 쓰면 모든 결과가 "주의"로 잘못 나온다.
그래서 기본값은 **단위·참고 범위 없음 → 숫자만 표시하고 정상/주의 판정을 하지 않는다** (참고 범위 칸은 `미설정`). 확정되면 `config.ini` 에 적는다:
```ini
[result]
title = Troponin
unit = ng/mL
ref_low = 0.0
ref_high = 0.040
method = EIS
```
- `title`: 결과 카드 제목 (기본 `Troponin`).
- `method`: 시안의 "면역형광법(FIA)" 은 이 장비의 측정 방식과 달라서 `EIS` 만 표시한다.
- 판정은 `value > ref_high` 또는 `value < ref_low` 이면 `주의`, 아니면 `정상`. QC 불합격(값 없음)은 `판정불가`.

## 4. 시안과 다른 점 (의도한 것)
| 시안 | 구현 | 이유 |
|---|---|---|
| 설정 버튼이 `⚙ 설정` 알약 | 톱니바퀴 아이콘 (로그인 화면과 같은 버튼) | 두 화면에서 같은 버튼을 쓴다 |
| 뒤로 가기 없음 | 왼쪽 위 `←` 추가 | 로그인 화면으로 돌아갈 방법이 필요 |

## 6. 세로 측정 화면 (480x800, 2026-10-25)
시안: 위에서부터 **프로필(가족 구성원 선택) → 검사 결과 → 검사 진행(3단계 줄) → 장비 상태 + 검사 이력 보기**.
| 영역 | 내용 |
|---|---|
| 상단 | `←`, 모델 탭(`Troponin` / `NT-ProBNP`), 날짜·시간(두 줄), 우측 끝은 설정 버튼 |
| 프로필 | 저장된 프로필 카드를 **눌러 선택**(한 번 더 누르면 해제), 카드 목록은 좌우로 밀어서 본다. 마지막의 **`+ 추가`** 카드로 새 프로필을 만든다. 선택하면 `편집` 버튼이 나타난다. 카드를 **길게(0.65초) 눌러도** 편집 |
| 검사 결과 | 가로와 같은 내용(값, 단위, 정상/주의, 참고 범위, 측정 시간 / 검증 완료 시간 / 검사 방법) |
| 검사 진행 | 단계마다 한 줄: 번호 · 삽화 · 이름/상태 · 설명(또는 타이머와 진행률) · **단계별 시작 버튼**. 오른쪽 위에 `처음부터` `중지` `모니터링` |
| 장비 상태 | 아이콘 3개: 장비(모듈 응답) / 키트(센서·포화) / 연결(UART 포트). 정상은 초록, 주의는 주황, 문제는 빨강 |
| 검사 이력 보기 | 누르면 이력 화면(최근 50건) |

- **장비 상태 아이콘(2026-10-26)**: `icon/` 폴더의 PNG(`power.png`, `kit_check.png`, `wifi.png`)를 쓴다. PNG 는 **투명도 마스크**로만 쓰고 색은 상태에 따라 **단색**으로 입힌다(정상 초록 `#1FA37A` / 주의 주황 `#C47A00` / 문제 빨강 `#C73838`, 배경 원은 기존 그대로). `kit_check.png` 는 파랑·분홍·빨강의 다색 그림이라 `python tools/make_status_icons.py` 로 단색 마스크 `icon/kit_check_mono.png` 를 만든다 (윤곽선·물방울은 진하게, 시험관 채움은 같은 색의 연한 농도로, 바깥 여백은 잘라냄). 아이콘 파일을 바꾸면 이 스크립트를 다시 실행한다. **Pi 에 `icon/` 폴더를 올려야 한다** (없으면 이전에 직접 그리던 아이콘으로 대체). 코드: `ui/dashboard_widgets.py` `tinted_icon`/`StatusIcon`, 시험: `tests/test_status_icon.py`.
- **프로필 선택 필수**: 프로필을 고르지 않으면 1단계가 시작되지 않고 안내가 뜬다 (`require_patient`). 선택한 프로필은 `result.json` / `summary.json` 의 `patient` 에 저장된다. **새 측정**을 시작하면 선택이 풀린다.
- **단계별 시작 버튼**: 현재 단계의 버튼만 활성화된다. 끝난 단계는 버튼이 사라지고 ✓ 가 보이며, 아직 안 온 단계는 회색이다. 혈액투입 단계는 반응 타이머가 끝나야 활성화된다. 결과가 나오면 3단계 줄의 버튼이 `새 측정` 이 된다.
- **프로필 저장**: `data/profiles.json` (앱 폴더 아래, 개인정보 포함). 임시 파일에 쓰고 바꿔치기해서 도중에 꺼져도 깨지지 않고, 읽을 수 없으면 `.bad` 로 옮기고 빈 목록으로 시작한다. **Pi 에 올릴 때 이 파일을 덮어쓰지 않는다** (`data/` 는 업로드 대상이 아님).
- **프로필 편집 화면** (`ui/profile_edit_page.py`): 필수(성명·성별·나이·몸무게)와 옵션(혈압·혈당·만성질환). 같은 이름은 허용하지 않는다. 삭제는 확인 후 가능하고, 이미 저장된 검사 결과는 지워지지 않는다. 터치 키보드가 열리면 아래에 키보드만큼 빈 칸을 늘려 마지막 입력란까지 올려 볼 수 있다.
- **시안과 다른 점**: 시안의 "키트 1개 사용" 문구는 뺐다(장비가 알 수 없는 값). `모니터링`/`처음부터`/`중지` 버튼은 시안에 없어서 검사 진행 카드 제목줄에 넣었다. 시안의 프로필(김민수·이서연·김하준)은 예시이고 실제 목록은 저장된 프로필이다. 1단계가 끝난 줄의 "2단계 시작 →" 버튼은 시안과 달리 해당 단계 줄에 둔다.
- **가로 화면과의 차이**: 가로는 환자 정보를 그 자리에서 입력하고, 세로는 저장된 프로필을 고른다. 두 방식을 맞추려면(가로도 프로필 선택으로) 말씀해 주세요.
